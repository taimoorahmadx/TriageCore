# Q3 · `llm_judge` baseline
Spec: FR-V1 · Owner: Abdul · Depends: Q4

**Goal:** answer "why not just ask the LLM?" with data.

**Read first:** `src/eval/evaluate.py`, `src/browser/relocator.py` (Groq call pattern only).

**Steps**
1. Create `src/eval/llm_judge.py`:
   - `class Judge(Protocol): def decide(self, step: dict) -> str: ...`
   - `class GroqJudge`: same HTTP pattern as `GroqRelocator` (urllib, timeout, retries). Prompt: the step name, risk tier, `raw_signals`, and the `observations` messages (each list cut to 5 items, 200 chars each). Ask for exactly one word in backticks: `heal`, `flag` or `escalate`. Parse with a regex; anything else → `"escalate"`.
   - `class FixedJudge(answer: str)` test double.
2. `evaluate(relocator=None, save=True, judge: Judge | None = None)`: when `judge` is given, add policy `llm_judge`. CLI: `python -m src.eval.evaluate --llm-judge` uses `GroqJudge()`.
3. Test: `evaluate(relocator=KnownRenames(), save=False, judge=FixedJudge("heal"))` has `llm_judge` in the summary with `masked_regressions == 4`.

**Check:** `.venv/bin/python -m pytest -q tests/test_pipeline.py`
**Stop and ask if:** Groq rate limits make the full suite fail; do not add sleeps longer than 2 s.
