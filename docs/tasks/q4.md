Spec: FR-V1 · Owner: Abdul · Depends: B2

**Goal:** test whether the Bayes engine adds anything over an obvious hand rule on the same evidence.

**Read first:** `src/eval/evaluate.py`, `tests/test_pipeline.py`.

**Steps**
1. Add `simple_rule(signals) -> str` to `evaluate.py`:
   - `"flag"` if `original_resolved_after_wait` is True and `expected_state_reached` is not False;
   - `"heal"` if `relocated_match_count == 1` and `expected_state_reached` is True and `uncaught_page_errors == 0` and `error_state_shown` is not True and `failed_requests == 0`;

**Check:** `.venv/bin/python -m pytest -q tests/test_pipeline.py` · `cd frontend && npm run build`
