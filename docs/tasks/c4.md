# C4 · Log truncation
Spec: FR-C2 · Owner: Shazil

**Read first:** `docs/spec.md` FR-C2 only.

**Steps**
1. Create `src/ci/truncate.py`:
   ```python
   @dataclass(frozen=True)
   class TruncatedLog:
       text: str
       truncated: bool
       original_tokens: int
       kept_tokens: int

   def estimate_tokens(text: str) -> int:  # ceil(len(text) / 4)
   def truncate_log(text: str, max_tokens: int = 16000, head_share: float = 0.3) -> TruncatedLog
   ```
   Work on whole lines. Head = first lines fitting `head_share * max_tokens`; tail = last lines fitting the rest minus the marker. Marker: `[... {n} lines removed by TriageCore ...]` on its own line. If a single line is longer than the whole budget, cut that line by characters.
2. `tests/test_truncate.py`: short text unchanged and `truncated=False`; a 100,000-line log → `truncated=True`, `kept_tokens <= max_tokens`, first line and last line preserved, exactly one marker line; empty string works; `head_share` respected within one line.

**Check:** `.venv/bin/python -m pytest -q tests/test_truncate.py`
