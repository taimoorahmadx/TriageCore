# B1 · Real-app QA cases
Spec: FR-V5 · Owner: Taimoor · Depends: Q4

**Goal:** at least 10 QA steps from a real open-source web app, so results are not only on the team's own pages. Selected candidate: [`1Marc/modern-todomvc-vanillajs`](https://github.com/1Marc/modern-todomvc-vanillajs) (CC BY 4.0 as stated in its README; attribution required). Recheck the licence file/terms and copied assets when preparing the app.

**Steps**
1. Confirm the selected candidate still meets the task constraints: static files, no build step, no backend, and licence/attribution recorded. The repository states that it uses native browser modules and has no build tools; serve it over HTTP (not `file://`). Record the final choice in `docs/log/changes.md`. If this check fails, stop and choose from `docs/research/qa-app-candidates-2026-11-02.md`.
2. Copy the app files to `tests/apps/modern-todomvc/`; include its licence/attribution and retain the source URL and commit SHA in a README. Do not copy repository tooling or unrelated assets.
3. Write `tests/apps/<name>/mutations.md` listing each mutation: selector rename (harmless), rename + handler throws, rename + handler no-op, rename + request fails, slow render. Implement each mutation as a query flag handled by a small script you add to the copied app (the original files stay untouched apart from that one script tag).
4. Add the scenarios to `tests/scenarios/qa_scenarios.yaml` under a comment `# real app: <name>`, with ground truth written **before** running anything.
5. Serve `tests/apps/` like `tests/dummy/` (extend `serve_directory` root or add a second mount); keep existing scenarios working.
6. Run `make eval` and record the result in `docs/progress.md`.

**Done when:** ≥ 10 new steps (≥ 4 regressions), evaluation runs, labels committed before results.
**Stop and ask if:** the app needs a backend or a build step that is not static.
