# A6 · CI workflow for this repository
Spec: NFR-9, plan §5 · Owner: Taimoor · Depends: A5

**Goal:** every pull request and every push to `main` runs lint, the full test suite and the
frontend build on GitHub Actions, so broken changes are caught before they reach `main`.

**Read first:** `Makefile`, `pyproject.toml`, `frontend/package.json`.

**Steps**
1. Run `make lint` locally and count the findings. If there are any, record the count in
   `docs/progress.md` under Lessons. Do **not** fix them in this task.
2. Create `.github/workflows/ci.yml` with two jobs, triggered `on: pull_request` and `on: push` to `main`:
   - **python** (`ubuntu-latest`):
     1. `actions/checkout@v4` with `fetch-depth: 0`;
     2. `actions/setup-python@v5` with `python-version: "3.10"` and `cache: pip`;
     3. `pip install -e ".[dev]"`;
     4. `python -m playwright install --with-deps chromium`;
     5. ruff on changed Python files only, so pre-existing findings don't fail every PR:
        `git diff --name-only --diff-filter=ACMR origin/${{ github.base_ref || 'main' }}...HEAD -- '*.py' | xargs -r ruff check`;
     6. `python -m src.core.weights`;
     7. `python -m pytest -q`.
     No step may need `GROQ_API_KEY`: the tests use stand-ins.
   - **frontend** (`ubuntu-latest`, `working-directory: frontend`): `actions/setup-node@v4` with
     `node-version: 20` and `cache: npm` (`cache-dependency-path: frontend/package-lock.json`), then
     `npm ci`, `npm run lint`, `npm run build`.
3. Add a "CI" line to `docs/contributing.md` step 5: "A pull request must be green before review."

**Check**
- Push the branch and open a pull request: both jobs pass. Paste the run URL into `docs/progress.md`.
- Break one engine test locally on a throwaway branch, push it: the python job fails. Delete that branch.

**Done when:** both jobs pass on the pull request and the deliberate failure was caught.
**Stop and ask if:** the browser tests are flaky on GitHub runners (they pass locally but fail
there more than once). Do not add retries or skip markers without asking.
