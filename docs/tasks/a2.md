# A2 · Move the POC into `archive/poc/`
Spec: FR-A1, FR-U4 · Owner: Taimoor · Depends: A1

**Goal:** POC code lives in `archive/poc/`, still runs, and `poc_api/` is gone.

**Read first:** `poc_api/main.py`, `src/api/app.py`, `poc_recovery.py` lines 120–135 and 370–390, `demo_safe.py`, `demo_trap.py`, `.ignore`, `pyproject.toml` (ruff section), `Makefile`.

**Steps**
1. `git mv poc_recovery.py demo_safe.py demo_trap.py archive/poc/` (create `archive/__init__.py` and `archive/poc/__init__.py`, both with a one-line docstring "Scripted proposal-stage demo; never cite its numbers.").
2. In `archive/poc/poc_recovery.py`, add `REPO_ROOT = Path(__file__).resolve().parents[2]` after the imports, and replace every `Path(__file__).resolve().parent` with `REPO_ROOT` (3 places: around lines 127, 130, 376).
3. In both demo files replace `from poc_recovery import` with `from archive.poc.poc_recovery import`.
4. Create `archive/poc/legacy_routes.py`: move every model and both routes from `poc_api/main.py` into it, using `router = APIRouter(tags=["legacy-poc"])` and `@router.post(...)` instead of `@app.post(...)`. Import `run_scenario` from `archive.poc.poc_recovery`. Drop the `sys.path` hack.
5. In `src/api/app.py` add, after the qa router: `from archive.poc.legacy_routes import router as legacy_router` and `app.include_router(legacy_router)  # scripted proposal demo (archive/poc), never cite`.
6. `git rm -r poc_api`.
7. Update references from `poc_api.main:app` to `src.api.app:app` in: `Makefile` (`api` target), `AGENTS.md` (Commands), `README.md`, `frontend/src/qa/QAEngineScreen.jsx` (the "API not reachable" hint text only).
8. `pyproject.toml`: remove the `"poc_api/main.py" = ["E402"]` per-file-ignore; add `"archive"` to `[tool.ruff] extend-exclude`.
9. `.ignore`: replace the three POC root files with one line `archive/`. Keep the `tests/dummy` and `frontend/public` legacy page lines.

**Check**
```bash
.venv/bin/python -c "from src.api.app import app; p={r.path for r in app.routes}; print(all(x in p for x in ['/health','/api/qa/run','/api/poc/run','/api/ci/triage']))"   # True
.venv/bin/python -c "import archive.poc.demo_safe, archive.poc.demo_trap"   # no error
make test
make api   # then in another terminal:
curl -s localhost:8000/api/qa/status        # {"engine_ready":true,...}
curl -s -X POST localhost:8000/api/ci/triage -H 'Content-Type: application/json' -d '{"scenario":"flaky"}' | head -c 80   # JSON
```

**Done when:** all checks pass and `git status` shows `poc_api/` deleted.
**Stop and ask if:** `poc_recovery.py` references any other root-relative path not listed above.
