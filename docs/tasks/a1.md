# A1 · Single FastAPI app
Spec: FR-A1 · Owner: Taimoor

**Goal:** the real app lives in `src/api/app.py`. No behaviour change.

**Read first:** `poc_api/main.py`, `src/api/qa_routes.py`, `Makefile`.

**Steps**
1. Create `src/api/app.py` containing:
   - module docstring: `Run: .venv/bin/python -m uvicorn src.api.app:app --port 8000`;
   - `REPO_ROOT = Path(__file__).resolve().parents[2]`;
   - `app = FastAPI(title="TriageCore API", version="0.2.0")`;
   - `CORSMiddleware` with exactly the six origins currently in `poc_api/main.py`, same other settings;
   - `app.mount("/tests/dummy", StaticFiles(directory=str(REPO_ROOT / "tests" / "dummy")), name="dummy")`;
   - `app.include_router(qa_router)` from `src.api.qa_routes`;
   - `@app.get("/health")` returning `{"status": "ok", "service": "triagecore-api"}`.
2. In `poc_api/main.py`: delete the `FastAPI(...)` construction, the CORS block, the static mount, the
   `qa_router` include and the `/health` route. Add `from src.api.app import app  # noqa: E402` after
   the `sys.path` insert. Keep every model and both `@app.post` routes unchanged.
3. Do not change `Makefile` yet (A2 does).

**Check**
```bash
# Route list = OpenAPI paths + mounts (works on all FastAPI versions). Run each line as its own process.
.venv/bin/python -c "from poc_api.main import app; p=set(app.openapi()['paths'])|({getattr(r,'path',None) for r in app.routes}-{None}); print(all(x in p for x in ['/health','/api/qa/run','/api/legacy/poc/run','/api/legacy/ci/triage','/tests/dummy']))"   # True
.venv/bin/python -c "from src.api.app import app; p=set(app.openapi()['paths'])|({getattr(r,'path',None) for r in app.routes}-{None}); print('/api/qa/run' in p, '/api/legacy/poc/run' in p, '/tests/dummy' in p)"   # True False True
make test        # all pass
```

**Done when:** both checks print as shown and tests pass.
**Stop and ask if:** anything in the frontend calls a route you would have to rename.
