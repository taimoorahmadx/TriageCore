# C14 · Demo reviewed historical CI runs
Spec: FR-C3, FR-C6, FR-C7 · Owner: Shazil · Depends: C3, C11, C13

**Goal:** Let the CI Engine screen analyze reviewed cases from the real GitHub Actions corpus, so the FYP-1 demo shows a real historical run rather than only the two synthetic smoke fixtures. This is offline, read-only corpus analysis; it does not connect a live repository.

**Read first:** `src/api/ci_routes.py`, `src/agents/ci_pipeline.py`, `src/eval/evaluate_ci.py`, `frontend/src/ci/CIEngineScreen.jsx`, `frontend/src/ci/api.js`, `docs/tasks/c3.md`, `docs/contracts/ci_signals.md`.

**Steps**
1. Add reviewed `tests/ci_corpus/` cases to the CI case catalogue and analysis route. Exclude cases without both a human-reviewed `label` and `label_source`; preserve the existing fixture cases and identify each case's source type.
2. In the UI, identify corpus entries as **Historical GitHub Actions run** and show repository, run ID, and a source link when one can be formed safely. Do not reveal the true label before analysis; after analysis, show it separately from the engine decision and indicate whether the recommendation matches the reviewed label.
3. Display extraction failure distinctly from an ordinary model decision, using C13's status contract. Never fill missing extracted facts with invented values.
4. Keep the run read-only: no webhook, GitHub credential, repository writes, rerun, PR creation, or merge. State that the run uses a saved public log and may call the configured extractor.
5. Add route and UI tests for reviewed-case filtering, source metadata, and a completed analysis; preserve fixture-case behavior.

**Check:** `.venv/bin/python -m pytest -q tests/test_ci_pipeline.py tests/test_ci_routes.py` · `cd frontend && npm run lint` · `cd frontend && npm run build`.

**Done when:** The local CI screen can analyze at least one human-reviewed historical run and show its source, extracted evidence, trace, decision, and post-analysis ground truth without implying live GitHub integration.
**Stop and ask if:** the corpus does not contain a safely shareable reviewed case, source attribution is ambiguous, or the feature requires credentials or a change to the approved CI evidence/label contract.
