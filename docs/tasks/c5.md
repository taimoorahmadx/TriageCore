# C5 · Webhook endpoint
Spec: FR-C1, NFR-4, I9 · Owner: Shazil · Depends: A1, S1

**Read first:** `src/api/app.py`, `src/db/store.py`, `docs/contracts/decision_record.md` (`ci_jobs`).

**Steps**
1. Create `src/ci/webhooks.py` with `router = APIRouter(prefix="/api/ci", tags=["ci"])` and `POST /webhook`. Use `async def` here (unlike the QA routes) because it needs `await request.body()`: the signature is computed over the exact raw bytes. The handler does no Playwright work, so async is safe.
   1. Secret = `os.environ.get("GITHUB_WEBHOOK_SECRET")`; empty → 503 `{"detail": "webhook secret not configured"}`.
   2. Header `X-Hub-Signature-256` must equal `"sha256=" + hmac.new(secret, body, sha256).hexdigest()` using `hmac.compare_digest`; missing or wrong → 401. Do this **before** parsing JSON.
   3. Parse JSON; failure → 400. Header `X-GitHub-Event` missing → 400.
   4. Event ≠ `workflow_run`, or `action` ≠ `completed`, or `workflow_run.conclusion` ≠ `failure` → 202 `{"accepted": false, "reason": "..."}`.
   5. Required fields `workflow_run.id`, `workflow_run.head_sha`, `repository.full_name`, header `X-GitHub-Delivery`; any missing → 400.
   6. `default_store().save_ci_job(...)` with state `pending` → 202 `{"accepted": true, "run_id": <id>, "job_id": <id>}`.
   7. Any other exception → 400 with a generic message (never 500 on bad input); log the exception server-side.
2. Include the router in `src/api/app.py`. Exempt it from the API token (FR-A3, task D1).
3. Fixtures in `tests/fixtures/webhooks/`: `workflow_run_failure.json` (minimal valid), `workflow_run_success.json`, `not_json.txt`, `missing_head_sha.json`, `push_event.json`.
4. `tests/test_webhooks.py` with `TestClient`, `monkeypatch.setenv("GITHUB_WEBHOOK_SECRET", "test-secret")`, `TRIAGECORE_DB_PATH` pointing at `tmp_path`: valid → 202 accepted; bad signature → 401; no signature → 401; secret unset → 503; not JSON (signed) → 400; missing field (signed) → 400; success conclusion → 202 not accepted; push event → 202 not accepted; duplicate delivery → same job id; each request < 2 s.

**Check:** `.venv/bin/python -m pytest -q tests/test_webhooks.py`
