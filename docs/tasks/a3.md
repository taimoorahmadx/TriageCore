# A3 · Isolate legacy frontend screens
Spec: FR-U4 · Owner: Taimoor · Depends: A2

**Goal:** `App.jsx` only knows three tabs; all scripted screens live in `frontend/src/legacy/` and still work.

**Read first:** `frontend/src/App.jsx`, `frontend/src/components/Navbar.jsx`.

**Steps**
1. `git mv` these from `frontend/src/components/` to `frontend/src/legacy/`: `PipelineSimulator.jsx`, `ReliabilityDashboard.jsx`, `QADetailScreen.jsx`, `CIDetailScreen.jsx`, `PRReviewScreen.jsx`, `BenchmarkScreen.jsx`, `EvidenceDrawer.jsx`, `DiffView.jsx`, `ConfidenceDial.jsx`, `AgentBadge.jsx`, `StatusPill.jsx`. Keep `Navbar.jsx` and `TriageCoreLogo.jsx` in `components/`. Fix relative imports inside the moved files (they import each other with `./`, which still works; any `../` import must be checked).
2. Create `frontend/src/legacy/LegacyPoc.jsx` exporting `LegacyPoc()`. Move into it, unchanged: the `drawerOpen/drawerAgent/drawerTrace`, `prContext`, `qaState`, `feedItems` state; `handleUpdateQaState`, `handleNavigate` (local screen switch, default screen `'simulator'`), `handleOpenDrawer`, `handleSelectFeedRow`, `handleResolvePR`; the render branches for `simulator`, `dashboard`, `qa-detail`, `ci-detail`, `pr-review`, `benchmark`; and the `EvidenceDrawer`. Add a one-line banner at the top: "Proposal-stage demo. Numbers on these screens are scripted, not measured."
3. `App.jsx`: keep `currentScreen` with values `qa-engine`, `evaluation`, `simulator`; render `<QAEngineScreen/>`, `<EvaluationScreen/>`, `<LegacyPoc/>`. Remove all other state and imports. Keep the footer.
4. Do not change any text, style or logic inside the moved screens.

**Check**
```bash
cd frontend && npm run lint && npm run build     # both succeed
```
Then `make api` + `make ui`, open http://localhost:5173 and click: QA Engine, Evaluation, Proposal PoC; inside the PoC click through to the dashboard and the benchmark screen and back. No console errors (browser devtools).

**Done when:** build passes and all screens render.
**Stop and ask if:** a moved screen imports something from `qa/`.
