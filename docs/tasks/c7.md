# C7 · Commit tracing
Spec: FR-C4, I3 · Owner: Shazil · Depends: C1

**Read first:** `docs/contracts/ci_signals.md`.

**Steps**
1. Create `src/ci/tracing.py`:
   ```python
   @dataclass(frozen=True)
   class Commit:
       sha: str
       author: str
       files: tuple[str, ...]

   @dataclass(frozen=True)
   class Attribution:
       attributed_commit: str | None
       candidates: tuple[str, ...]
       ambiguous_commit: bool
       dependency_change: bool

   def attribute(failing_files: list[str], commits: list[Commit], max_commits: int = 10) -> Attribution
   ```
   Use only the first `max_commits` (most recent first). Path match: exact, or the failing path ends with `/` + commit file, or vice versa (logs often print relative paths). One candidate → attributed; ≥ 2 → `ambiguous_commit=True`, attributed `None`; 0 → both falsy. `dependency_change` = any commit touches a manifest/lockfile from the list in `ci_signals.md`.
2. `tests/test_tracing.py`: single match; two commits touch the same file → ambiguous; no match; 11 commits with the only match at position 11 → not attributed; relative-path match; lockfile → `dependency_change=True`.

**Check:** `.venv/bin/python -m pytest -q tests/test_tracing.py`
