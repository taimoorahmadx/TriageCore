# S1 · SQLite decision store
Spec: FR-E10, FR-A2 · Owner: Taimoor · Depends: A1

**Read first:** `src/agents/qa_pipeline.py`, `src/api/qa_routes.py`, `docs/contracts/engine_io.md`.

**Steps**
1. Write `docs/contracts/decision_record.md`: one table, `decisions`, columns `id INTEGER PRIMARY KEY`, `created_at TEXT` (ISO-8601 UTC), `source TEXT` (`qa`/`ci`), `run_id TEXT` (uuid4 per scenario/case run), `case_id TEXT` (scenario id or corpus case id), `step_id TEXT` (null for CI), `status TEXT` (`triage`/`error`), `classification TEXT` null, `recommended_action TEXT`, `confidence_score INTEGER` null, `evidence_json TEXT`, `output_json TEXT` null, `details_json TEXT` null, `error TEXT` null. Plus a second table `ci_jobs` for C5: `id`, `received_at`, `delivery_id TEXT UNIQUE`, `repo TEXT`, `run_id INTEGER`, `head_sha TEXT`, `payload_json TEXT`, `state TEXT DEFAULT 'pending'`.
2. Create `src/db/store.py`:
   - `class DecisionStore(Protocol)`: `save_decision(record: dict) -> int`, `list_decisions(limit: int = 50, source: str | None = None) -> list[dict]`, `save_ci_job(job: dict) -> int`.
   - `class SqliteStore(path: Path)`: creates parent dir and tables on init (`CREATE TABLE IF NOT EXISTS`); one connection per call; JSON via `json.dumps`; `save_ci_job` with an existing `delivery_id` returns the existing id (idempotent).
   - `def default_store() -> SqliteStore` reading `TRIAGECORE_DB_PATH` (default `data/triagecore.sqlite3` under the repo root).
3. `run_scenarios(..., store: DecisionStore | None = None)`: when given, save one record per triaged or error step. `evaluate()` must **not** store (pass nothing).
4. `qa_routes.py`: `/run` passes `default_store()`; add `GET /api/qa/decisions?limit=50` (1–500, 422 otherwise) returning `list_decisions(limit, "qa")`.
5. `tests/test_store.py` (uses `tmp_path`, no browser): save two records, list newest first, JSON round-trips, duplicate `delivery_id` returns the same id.

**Check:** `.venv/bin/python -m pytest -q tests/test_store.py` · `make test`
**Done when:** checks pass and one live `/api/qa/run` adds rows (`curl -s 'localhost:8000/api/qa/decisions?limit=3'`).
