# C1 · CI evidence contract
Spec: FR-C3, FR-C5 · Owner: Shazil · Depends: C2

**Goal:** the CI equivalent of `raw_signals.md`. **Shazil decides the groups**; the agent drafts and explains options. No probabilities in this task.

**Read first:** `docs/contracts/raw_signals.md`, `docs/contracts/engine_io.md`, `docs/brief.md` (glossary), `src/core/evidence.py` (`QAAdapter` only).

**Steps**
1. Draft `docs/contracts/ci_signals.md` with the same sections as `raw_signals.md`: `CILogFacts` (what the LLM extracts), `raw_signals` (CI), `context` (CI), evidence groups with states, hard preconditions, open questions.
2. Starting proposal to present to Shazil (he may change any of it):
   - `CILogFacts`: `failure_kind` (enum: `test_assertion`, `compile_or_syntax`, `import_or_missing_module`, `dependency_resolution`, `network_or_timeout`, `runner_or_resources`, `other`, or null), `failing_files` (list of repo paths, max 20), `error_excerpt` (≤ 300 chars, for the trace only, never weighted).
   - Groups: `failure_kind` (states as above, `other` included); `rerun_history` (`passed_on_rerun`, `failed_on_rerun`; null if not rerun); `dependency_change` (`changed`, `unchanged`: did any of the recent commits touch a manifest/lockfile such as `package.json`, `package-lock.json`, `requirements*.txt`, `pyproject.toml`, `poetry.lock`, `go.sum`); `code_link` (`failing_file_touched`, `not_touched`; null if no failing files).
   - `context`: `risk_tier` (required), `truncated` (bool), `ambiguous_commit` (bool), `attributed_commit` (sha or null), `repo`, `run_id`, `case_id`.
   - Precondition: `auto-fix` blocked unless `attributed_commit` is set and `ambiguous_commit` is false.
   - Open question for Shazil: should `truncated=true` be its own group, or just make `failure_kind` null when the error text was cut?
3. Show the draft to Shazil and record his decisions in the file. Then set the status line at the top to `v1, approved by Shazil (date)`.

**Done when:** the file exists with Shazil's approval line.
**Stop and ask:** before writing any probability or cost (that is C9).
