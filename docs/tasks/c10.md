# C10 · CI pipeline and evaluation
Spec: FR-C6, FR-V4, NFR-5 · Owner: Shazil · Depends: C3, C6, C9

**Read first:** `src/agents/qa_pipeline.py` (structure only), `src/eval/evaluate.py` (structure only), `src/eval/stats.py`, `docs/contracts/ci_signals.md`.

**Steps**
1. `src/agents/ci_pipeline.py`: `load_cases(dir)`, `run_case(case, engine, extractor, store=None) -> dict` (truncate → mask → facts → tracing → build `ConfidenceEngineInput(source="ci", ...)` → `evaluate_detailed` → score vs label), `run_cases(ids=None, ...)`. Unexpected exceptions → `status: "error"`, escalate (same as A4).
2. Scoring: masked = label is `bug` or `dependency` and action is `rerun`; or label is `flaky`/`infra` and action is `auto-fix` (wrong fix). Needless escalation = `escalate` when the label's correct action exists and is not escalate.
3. `src/eval/evaluate_ci.py`: policies `rerun_all` (always `rerun`), `keyword_rule` (regex on the log: `timeout|ECONNRESET|503` → `rerun`; `npm ERR|ModuleNotFoundError|could not resolve` → `auto-fix`; else `escalate`), `triagecore`. Same summary fields and Wilson intervals as QA, plus p50/p95 duration. Save `results/ci_eval_<stamp>.json/.csv` and `results/ci_eval_latest.json` (add `!results/ci_eval_latest.json` to `.gitignore`).
4. `src/api/ci_routes.py`: `GET /api/ci/cases`, `POST /api/ci/run {"case_id": ...}`, `GET /api/ci/evaluation/latest`. Include in `app.py`.
5. Tests with `FixedFactExtractor` and two small fixture cases in `tests/fixtures/ci_cases/`.

**Check:** `make test` · `.venv/bin/python -m src.eval.evaluate_ci` prints a summary table.
