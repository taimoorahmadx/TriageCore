# D1 · Docker deployment on a VM
Spec: NFR-8, FR-A3 · Owner: Taimoor · Depends: A5, S1

**Read first:** `src/api/app.py`, `frontend/src/qa/api.js`, `frontend/vite.config.js`, `pyproject.toml`.

**Steps**
1. `frontend/src/qa/api.js`: `export const API_BASE = import.meta.env.VITE_API_BASE ?? 'http://localhost:8000';` (production build sets `VITE_API_BASE=""` so calls are same-origin).
2. API token (FR-A3): in `app.py`, a dependency that, when `TRIAGECORE_API_TOKEN` is non-empty, requires `Authorization: Bearer <token>` on every `POST` except `/api/ci/webhook`; 401 otherwise. Test in `tests/test_auth.py`.
3. `Dockerfile` (multi-stage): stage 1 `node:20-slim` builds `frontend/` with `VITE_API_BASE=""`; stage 2 `mcr.microsoft.com/playwright/python:v<same version as installed playwright>-jammy`, `pip install .`, copy `src/`, `tests/dummy/`, `tests/scenarios/`, `tests/apps/` if present, `archive/`, built `frontend/dist`. `app.py` serves `frontend/dist` at `/` only when the folder exists. `CMD uvicorn src.api.app:app --host 0.0.0.0 --port 8000`.
4. `compose.yaml`: one service, `env_file: .env`, volume `./data:/app/data`, port `8000:8000`.
5. **Human:** create a small VM, install Docker, copy the repo and `.env` (with `TRIAGECORE_API_TOKEN` set), run `docker compose up -d --build`, open the firewall for port 8000 only.
6. Add a "Deploy" section to `docs/troubleshooting.md` with the exact commands used.

**Check:** from a different machine: `curl -s http://<vm-ip>:8000/health` → ok; a `POST /api/qa/run` without the token → 401; with the token → a result. Record the VM provider and date in `docs/progress.md`.
**Stop and ask if:** the VM has < 2 GB RAM (Chromium needs it) or costs money beyond free credit.
